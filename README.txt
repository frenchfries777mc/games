  img/                게임 미리보기 그림 2장

[ 올리는 방법 ]
  1. GitHub에서 새 저장소를 만들고 이름을 frenchfries777mc.github.io 로 정하기
  2. 이 압축을 풀어 나온 파일과 img 폴더를 모두 올리기
  3. Settings > Pages > Deploy from a branch > main / (root) > Save
  4. 주소: https://frenchfries777mc.github.io/
